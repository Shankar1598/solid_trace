# v0.14.0 (2026-10-25)

Fixes the known security vulnerabilities in every component, fits every page to a phone, and lays the Overview out as a dashboard. It's still a 0.x prototype, not yet hardened for production.

## Security

- **Dependencies past their known vulnerabilities.**
  - Console: Rails 8.1.4, rack, puma, nokogiri, net-imap, sqlite3 and the other flagged gems; the JS packages, with Vite 6, Vitest 4 and shadcn 4.
  - EventStore: Fiber 2.52.13, gRPC 1.83.2, x/net 0.60.0 and the OpenTelemetry SDK 1.45; tokio 1.54.1 in the VRL runtime.
- **Images.** Console builds on Ruby 4.0.9, whose Debian base clears the fixable OS CVEs. Vector moves to 0.60.0 for OpenSSL's CVE-2026-14456.
- **brakeman 8's new warnings fixed.** The invite and sign-up pages answer HEAD as they answer GET, and changing a member's role takes only the role.
- **`bin/security`** scans every component locally: gems, Rails code, JS packages, Go modules, the VRL crate, secrets in git's history, and the images the install runs.

## Added

- **Phones.** Below tablet width a top bar opens the sidebar as a drawer, Settings pages get a row of tabs, the Issues list wraps its filters, and a Dashboard stacks its charts in one column.
- **A right value axis on Charts.** Two columns that measure different things, drawn as lines or areas, share one plot, the second over a right axis with dashed lines.
- **A shared hover line on Dashboards.** Hovering a time on one chart marks it on the others.

## Changed

- **Sign-in, an invite and a new Organization land on the Overview**, not Issues.
- **The Overview is a dashboard of panels** that fits about one view on a wide screen; each panel's description sits behind an info mark. Compared with other tools is off the page for now; `get_overview` still answers it.
- **Console's exceptions are one Log.** An entry of several lines, such as an exception and its backtrace, is written as one JSON line, so Vector ships it whole.

## Upgrading from v0.13.0

No migrations and no config changes. `deploy/install` pulls the new Console, EventStore and Vector images.

```bash
git fetch --tags && git checkout v0.14.0 && deploy/install
```

- What it ships: the security fixes (`security/console-deps`, `security/event-store-deps`) and `bin/security`; the phone layout (`feature/phone-layout`); a Chart's right value axis (`feature/chart-right-axis`) and the shared hover line (`feature/chart-hover-line`); the Overview as panels and landing on it; Console's multi-line log entries as one JSON line.
- Tagged on `main` at `a4cdeaf`. No migrations and no config changes; the Vector image moves to 0.60.0.
