# v0.21.1 (2026-11-18)

A security patch for Console's and EventStore's images: it fixes the image findings that have a fix. It's still a 0.x prototype, not yet hardened for production.

## Security

- EventStore: `golang.org/x/net` 0.62.0 (CVE-2026-78661), with `x/crypto` 0.58.0, `x/sync` 0.24.0, `x/sys` 0.49.0 and `x/text` 0.43.0. EventStore's code didn't call the defect.
- Console: `thruster` 0.1.28, whose binary has `golang.org/x/net` 0.62.0 (CVE-2026-78661).
- Console's image now installs Debian's security updates over the Ruby image, so it has `zlib1g` `1+deb13u1` (CVE-2026-85091), and later fixes at each build.

## Upgrading from v0.21.0

No migrations and no change in `deploy/`.

```bash
git fetch --tags && git checkout v0.21.1 && deploy/install
```
