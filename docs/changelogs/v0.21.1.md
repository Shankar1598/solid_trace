# v0.21.1 (2026-11-18)

A security patch for Console's and EventStore's images: it fixes the image findings that have a fix. It's still a 0.x prototype, not yet hardened for production.

## Security

- EventStore: `golang.org/x/net` 0.62.0 (CVE-2026-78661), with `x/crypto` 0.58.0, `x/sync` 0.24.0, `x/sys` 0.49.0 and `x/text` 0.43.0. EventStore's code didn't call the defect.
- Console: `thruster` 0.1.28, whose binary has `golang.org/x/net` 0.62.0 (CVE-2026-78661).
- Console's image now installs Debian's security updates over the Ruby image, so it has `zlib1g` `1+deb13u1` (CVE-2026-85091), and later fixes at each build.

## Upgrading from v0.21.0

No migrations and no change in `deploy/`.

```bash
git fetch --tags && git checkout v0.21.1 && deploy/install
```

## Release record

- What it ships: the dependency and image fixes (`f2989229`), on v0.21.0.
- Migrations: none. `deploy/`: no change.
- Security findings before tagging:
  - GitHub, Dependabot: two moderate alerts, opened at 19:01 UTC, after v0.21.0's check. They were not checked again before this tag, and were seen only at the push. Both are GHSA-q7gw-24fr-5p69: `go.opentelemetry.io/otel/sdk` 1.45.0 and `otel/trace` 1.46.0 in EventStore (fixed in 1.47.0), where `AttributeValueLengthLimit` can be bypassed. They are indirect, through the GCS client. EventStore's code sets no attribute limit, and govulncheck finds that it doesn't reach the defect. They stay open for the next release.

In Console's base image, `apt-get upgrade` was run: it exits 0 with no prompt and installs `zlib1g` `1+deb13u1`. The `thrust` binary of `thruster` 0.1.28 has `golang.org/x/net` v0.62.0 (`go version -m`), as does the dev EventStore built on `f2989229`.
  - Left open, for their own changes: Vector 0.60.0 (musl, zlib; Dependabot PR #1 has 0.61.0), ClickHouse 26.8.34.13 (apt; PR #2 has 26.10, a new ClickHouse version under all Logs), and Caddy 2.11.8 (`golang.org/x/net`, and CVE-2026-116587 in go-jose, with no fixed Caddy image yet).
  - Scan images ran after this release's images were built (2026-11-18): it closed the 3 findings, on Console (`x/net` in `thruster`, `zlib1g`) and on EventStore (`x/net`). 7 stay open: Vector, ClickHouse and Caddy, as above.
  - `bin/security`: gems, rails, js, go and rust pass. secrets: no leak on `main`; the 14 findings are on local software-factory branches, as in v0.21.0.
