# v0.22.0 (2026-11-19)

Ingest can sit behind a load balancer that terminates TLS, with two new EventStore settings. `bin/upgrade` upgrades an install to a release in one command. It's still a 0.x prototype, not yet hardened for production.

## Added

- **Ingest behind a load balancer.** Two keys in `event_store.yml`, both shown on Settings → Instance:
  - `ingest_idle_timeout_seconds` is how long ingest keeps an idle keep-alive connection, 10 by default. Behind a load balancer, make it longer than the load balancer's keep-alive to its backends, or clients get 502s: 660 for GCP's classic Application Load Balancer, which keeps them 610 seconds. Keep the default where ingest faces the internet.
  - `ingest_refuse_forwarded_http`, off by default, answers 403 to an ingest request whose `X-Forwarded-Proto` says it came to the load balancer as plain HTTP, with a message that says to use an `https://` URL. It makes a client with an `http://` URL fail clearly; it is not a security control, as the client sent its key already. `/health`, and requests with no `X-Forwarded-Proto`, pass. When the header has a list of values, the last one is the load balancer's.

  [docs/install.md](../install.md) and `deploy/event_store.yml` have them.
- **`bin/upgrade`.** `bin/upgrade <tag>` upgrades an install to that release, and `bin/upgrade` to the newest one. It fetches the tags, checks out the release and runs `deploy/install`, which keeps the config and the secrets. It stops if the checkout has changes to tracked files.

## Security

- EventStore: OpenTelemetry 1.47.0 (`otel/sdk`, `otel/trace` and the rest), for GHSA-q7gw-24fr-5p69. They are indirect, through the GCS client, and EventStore's code didn't reach the defect.

## Upgrading from v0.21.1

No migrations. In `deploy/`, `event_store.yml` documents the two new keys, and the Caddyfile changes only a comment. A config without the keys works as before.

```bash
git fetch --tags && git checkout v0.22.0 && deploy/install
```

From this release on, `bin/upgrade v0.22.0` does the same.
