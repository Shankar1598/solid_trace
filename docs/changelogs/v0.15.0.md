# v0.15.0 (unreleased)

A draft, filled in as Traces' tickets merge.

## Added

- **Traces docs.** [docs/traces.md](../traces.md) shows how to turn tracing on, send to sentry.io and SolidTrace at once from one Ruby or Go SDK, put trace ids on Logs with request and Sidekiq middleware, and move them into the Logs' trace id with a Log transform.
- **SolidTrace traces itself.** Console sends the Transactions of 5% of its requests and jobs to the Meta Organization's Project. Its Logs carry their trace id, and the Project starts with the Log transform that reads it, so a Console request opens as a trace with its Logs.

## Changed

- **Console's Issues go to the Meta Organization's Project.** Console sends its own exceptions there with the DSN `deploy/install` writes, rather than to the DSN in its credentials, which it still uses when `SENTRY_DSN` is unset.

## Upgrading from v0.14.1

`deploy/install` adds two settings to `deploy/.env`, once: `SENTRY_DSN`, the Meta Project's DSN made from `META_PROJECT_KEY`, and `SENTRY_TRACES_SAMPLE_RATE=0.05`. Set the rate to `0` to trace none of Console's requests. `db_prepare` gives the Meta Project its Log transform, unless it has had one.
