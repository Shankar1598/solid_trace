# v0.14.1 (2026-10-25)

Updates Thruster, the proxy in front of Console's Rails server, past most of its known vulnerabilities. It's still a 0.x prototype, not yet hardened for production.

## Security

- **Thruster 0.1.27.** 0.1.17's binary was built with Go 1.25.5 and had 44 high and critical CVEs; 0.1.27's, built with Go 1.27.1, has 5, which only a newer Thruster release clears.

## Upgrading from v0.14.0

No migrations and no config changes.

```bash
git fetch --tags && git checkout v0.14.1 && deploy/install
```

Images, for `linux/amd64` and `linux/arm64`:

- `ghcr.io/shankar1598/solid-trace-console:v0.14.1`
- `ghcr.io/shankar1598/solid-trace-event-store:v0.14.1`

## Release record

- Ships Thruster 0.1.27 in Console's bundle; nothing else changed since v0.14.0.
- Checked: the settings Console passes (`HTTP_PORT`, `TARGET_PORT`, `LOG_REQUESTS`) are in 0.1.27's README; `bin/thrust` started, proxied a request (200) and stopped on a signal; its JSON log lines keep `time`, `level` and `msg`; `bin/bundler-audit` finds nothing. 0.1.27's binary scanned with trivy before the update.
- No test suites were run: only the lockfile changed.
