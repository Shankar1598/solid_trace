# v0.5.0 (2026-10-19)

You can switch Organizations from the sidebar now, and inviting from the Members page works again. It's still a 0.x prototype, not yet hardened for production.

## What's new

- **Switch Organizations from the sidebar and palette.** With two or more Organizations, the sidebar header is a dropdown of them, by name. Switching opens the same section in the other Organization. The command palette has an Organizations group too. `/` opens the Organization you last used.

## Fixes

- **Inviting from the Members page works.** Every invite from the page failed with a 400, because the page sent the form under the wrong key. Note that the invite is still emailed, so on an install without mail the invited person isn't told yet. Invite links, which an admin copies and shares, come in the next release.
- **Production installs no longer get the development users.** `db:seed` made `admin@solidtrace.local` and `member@solidtrace.local`, with password `password123`, and a Project with key `testkey123`, on every fresh database. It now makes them only in development and test. If your install has them, change their passwords or remove them. The oldest of them may be your Meta Organization's admin.
- **`deploy/setup-gcp` asks about the bucket and service account one command at a time.** The project ID and bucket location default to the VM's. The service account is now `solid-trace`.

## Upgrading from v0.4.0

There are no migrations and no config changes.

```bash
git fetch --tags && git checkout v0.5.0 && deploy/install
```

## Install

On a Debian or Ubuntu machine, x86 or Arm:

```bash
git clone --branch v0.5.0 https://github.com/Shankar1598/solid_trace.git
cd solid_trace
deploy/setup-gcp
```

Images, for `linux/amd64` and `linux/arm64`:

- `ghcr.io/shankar1598/solid-trace-console:v0.5.0`
- `ghcr.io/shankar1598/solid-trace-event-store:v0.5.0`
