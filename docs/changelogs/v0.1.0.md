# v0.1.0 (2026-10-19)

The first release of SolidTrace: self-hosted error tracking and Logs, with Sentry-compatible ingest. It's a 0.1 prototype, not yet hardened for production.

## What's in it

- **Console** (Rails): Projects, Issues, Integrations, the Logs explorer with charts, Dashboards, Monitors (Slack, PagerDuty, email), SQL queries scoped to a Project, and an MCP server for agents.
- **EventStore** (Go): Event and Log ingest on Sentry's protocol, with Pebble and DuckDB, and Log files and the Event archive optionally in a GCS or S3 bucket.
- **Install on a VM**: `deploy/setup-gcp` walks through the public URLs, HTTPS, email and storage, then runs `deploy/install`.
- **HTTPS with no domain**: Caddy gets a Let's Encrypt certificate for the VM's public IP. Console is on `https://<ip>`, ingest on `https://<ip>:4443`.

## Install

On a Debian or Ubuntu machine:

```bash
git clone --branch v0.1.0 https://github.com/Shankar1598/solid_trace.git
cd solid_trace
deploy/setup-gcp
```

At this tag, `deploy/install` pulls the release's images instead of building them:

- `ghcr.io/shankar1598/solid-trace-console:v0.1.0`
- `ghcr.io/shankar1598/solid-trace-event-store:v0.1.0`
