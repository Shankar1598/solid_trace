# v0.7.0 (2026-10-21)

Each Project can now reshape its Logs as they arrive, with a VRL program, and sign-up is closed once an install has a user. It's still a 0.x prototype, not yet hardened for production.

## What's new

- **Log transform.** Each Project has one [VRL](https://vector.dev/docs/reference/vrl/) program that runs on its Logs before they're stored. It can set, change and remove Fields, and drop whole Logs.
  - Admins edit it on the Project's Log transform page, linked from its settings, with a preview against the Project's recent Logs. Members can read it and preview drafts, but not save.
  - Every saved version is kept, and restoring one saves it again.
  - A change applies to Logs processed after it; stored Logs keep what they had. A Log the program fails on is stored as it arrived, with the error in `solidtrace.transform_error`.
  - MCP: `get_log_transform`, `preview_log_transform` and `update_log_transform`.
- **Sign-up is closed once the install has a user.** The first person to open a new install can still sign up; after that, people join by Invite. The log-in page no longer offers sign-up, and the sign-up page says to ask an admin for an invite. To let anyone sign up, run `instance_settings:set SIGN_UP_OPEN=true` (see Upgrading).
- **Log-in and sign-up are rate-limited** to 10 tries in 3 minutes per IP, as password resets and invite links already were.
- **Chart lines join across empty bins.** A series with sparse values, such as `max()` in minute bins over a day, draws as a line instead of scattered dots. A count that arrives on a slower rhythm than its bins, such as once a minute in 30-second bins, no longer drops to zero between every two values; a real gap still shows as zero.

## Upgrading from v0.6.0

Two migrations add `log_transform_versions` and `instance_settings.sign_up_open`. Console runs them when it starts, so there's nothing to do by hand. There are no config changes.

Sign-up closes on upgrade. If your install relied on people signing themselves up, open it again:

```bash
sudo docker compose -f deploy/docker-compose.yml exec console bin/rails instance_settings:set SIGN_UP_OPEN=true
```

```bash
git fetch --tags && git checkout v0.7.0 && deploy/install
```
