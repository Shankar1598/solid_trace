# v0.6.0 (2026-10-20)

You can invite people without mail set up now: copy their invite link from the Members page and send it however you like. It's still a 0.x prototype, not yet hardened for production.

## What's new

- **Invited members.** Inviting someone who has no password yet makes them Invited. Their row on the Members page has an "Invited" badge, for everyone. Someone who already has a password is added at once, as before.
- **Invite links.** Admins get a button on each Invited row that copies the person's invite link. Copying works over plain HTTP too, and if the browser won't copy, the link opens selected for you to copy by hand.
  - Opening the link asks for a name and a password, then signs the person in to that Organization's Issues.
  - A link stops working after seven days, once a password is set, or when you revoke the invite. The trash button on an Invited row reads "Revoke invite".
  - A password reset also ends someone's Invited state.
- **No passwords by email.** When mail is set up (`SMTP_ADDRESS` in production), the invite email carries the invite link. Without mail, nothing is sent and the notice tells you to copy the link from the table.
- **MCP `invite_member`** returns `invite_link` for someone Invited, so an agent can hand it over. For someone new its `outcome` is now `"invited"`, not `"added"`, and inviting someone already Invited answers `"already_invited"` with the link.

## Upgrading from v0.5.0

One migration adds `users.invited`. Console runs it when it starts, so there's nothing to do by hand. There are no config changes.

Invite links, emailed ones too, are built from the address you opened the Console at, not from `CONSOLE_URL`.

```bash
git fetch --tags && git checkout v0.6.0 && deploy/install
```

## Install

On a Debian or Ubuntu machine, x86 or Arm:

cd solid_trace
deploy/setup-gcp
