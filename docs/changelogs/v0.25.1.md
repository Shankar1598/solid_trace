# v0.25.1

A point release with fixes. Console no longer gives HTTP 500 now and then when two requests come at the same time, and a New monitor form keeps its errors. The tooltip of a time chart lists the largest value first. The EventStore and Dispatcher images get the security fix of `libpam`. It's still a 0.x prototype, not yet hardened for production.

## Added

- **`/solidtrace:beta-pr-review-canvas` (beta).** It makes an HTML page that walks a reviewer through a Bitbucket or GitHub PR, or the PR file of `open-pr local`: the summary and the risks of the PR body first, the core files open with notes, and the files to skim collapsed. Code that moved shows in blue or purple. It serves the page on `127.0.0.1:8432`. It is a copy of `pr-review-canvas` from Cursor's `cursor-team-kit` (MIT).

## Changed

- **The tooltip of a time chart lists the largest value first.** A chart split by groups keeps its 8 series with the largest sum of the first column. A column whose values do not add up, such as a max lag, now ranks its series by their peak, and the legend's note says so. Levels keep their worst-first order.

## Fixed

- **Console gave HTTP 500 now and then.** Two requests that read the Vite version at the same time (`config.version` in `console/config/initializers/inertia.rb`) both changed the folder, and Ruby 4 refuses that with "conflicting chdir during another chdir block". One thread reads it at a time now. Parallel browser tests showed it on Settings → User.
- **A New monitor form could lose its errors.** When a preview ended just after a save that the server refused, the preview wrote back the session as it was before the save, so the form showed no errors. The preview endpoints no longer write the session.
- **The code editor could show a whole line in a keyword's colour,** after typed text replaced a selection that started in a keyword. The line keeps the editor's colour.
- **The EventStore and Dispatcher images** upgrade the base image's packages, as Console's image does. This takes `libpam` to 1.5.2-6+deb12u3, with the fix of CVE-2025-6020.

## Upgrading from v0.25.0

Upgrade the install. There are no migrations and no config changes.

```bash
bin/upgrade v0.25.1
```

Then each engineer runs the setup script again, to get the plugin with `beta-pr-review-canvas`.
