# v0.23.0 (2026-11-23)

SolidTrace records the Claude Code Agent sessions of an Organization's engineers, from the repositories that an Admin names, and shows them as pages and as Logs. This release also has the Factory module, which is off until an Admin sets a Dispatcher URL: the Dispatcher runs on a VM of its own, not on this install. It's still a 0.x prototype, not yet hardened for production.

## Added

- **Agent sessions.** See [docs/agent-sessions.md](../agent-sessions.md).
  - **Settings → Agent sessions:** an Admin adds the captured repositories (`host/workspace/name` or `host/workspace/*`), confirms, and turns Agent sessions on. This makes the Agent Project, which keeps Agent sessions for 180 days. Console records who confirmed, when, and for which repositories.
  - **Capture setup** gives each engineer the commands with the instance's version and addresses: install the `solidtrace` CLI, install the Claude Code plugin (or push it with managed settings), and sign in. An engineer sees a notice of the capture at sign-in.
  - Only an Agent session in a captured repository uploads. An SSH remote and an HTTPS remote of one repository give the same name.
  - The CLI uploads each transcript by offset, so a resume sends only the new part, and redacts secrets before upload. Settings → Instance has the redaction patterns.
  - EventStore keeps each transcript, and makes one Log for each line in the Agent Project. The **Agent sessions** page lists the Agent sessions with filters and totals. The **Agent session** page shows the timeline of person messages, agent replies and tool calls, with subagents inside their parent.
- **API tokens** can be limited to some actions and some Projects, and can expire. A token can make child tokens that fit inside it.
- **The Factory (off by default).** With a Dispatcher URL in Settings → Instance, Console shows the Runs pages, the Run page, the starter Factory Dashboard, a Factory section in each Project, and the Factory provider of an Integration. Without it, none of these show. See [docs/factory.md](../factory.md).

## Known limits

- A line of an Agent session that uploads late (for example the first upload of an old Agent session) has its upload time as its Log time in the Logs explorer. Its own time is in `original.time`. The Agent sessions pages show the own time.
- Write a captured repository with the web host (`bitbucket.org/...`), not the SSH host (`ssh.bitbucket.org/...`): an entry with the SSH host matches nothing.
