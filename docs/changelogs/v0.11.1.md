# v0.11.1 (2026-10-23)

Fixes reading Logs from before the switch to ClickHouse. It's still a 0.x prototype, not yet hardened for production.

## Fixed

- **Old Logs found by id.** On v0.11.0, reads of the Log files a DuckDB release wrote failed whenever they filtered on a Log's id, with `Statistics have min_value > max_value … for column 'id'`. That broke the newest page over a range reaching back before the upgrade, and opening an old Log; Console said EventStore was unavailable. Charts, tables and the histogram over old Logs were unaffected. DuckDB wrote the id statistics in byte order, which ClickHouse's UUID order doesn't keep. EventStore now reads old files' ids as bytes, and still skips row groups by time.

## Upgrading from v0.11.0

No migrations or config changes.

```bash
git fetch --tags && git checkout v0.11.1 && deploy/install
```

From a DuckDB release, upgrade straight to v0.11.1: its `deploy/install` runs v0.10.0's `prepare-clickhouse`, as v0.11.0's did.
