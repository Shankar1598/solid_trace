# v0.15.1 (2026-10-27)

Makes Performance read like the rest of the Console, and updates net-ssh past two advisories. It's still a 0.x prototype, not yet hardened for production.

## Changed

- **Performance in the sidebar** is an entry like Logs: it opens the Project last seen there, or the newest, rather than listing every Project under a heading. Switching Organization from Performance opens the other Organization's.
- **Performance** has Issues' filter row (the Project and environment, then the range) over a framed table. A Transaction new in the range says so once, by its name, and only when the period before had others to compare with. A phone keeps the Transaction, its p95 and the time it consumed.
- **A Transaction's page** leads with its numbers in a strip (sampled, per minute, p50, p95, p99, errors), and shows each part in a panel as the Overview does: p95 by release beside the releases, self time by op beside self time by group, then repeated Spans and the slowest traces.

## Security

- **net-ssh 7.3.8**, past GHSA-qpg5-fx6p-8cq3 and GHSA-vxj5-fg65-x765. It's in Console's bundle only for Kamal, which the install doesn't use.

## Upgrading from v0.15.0

No migrations and no config changes.
