# 03: Which licence does SolidTrace take?

Type: grilling
Status: resolved
Map: [SolidTrace Software Factory](../map.md)

## Question

The factory is open source and self-hosted ([What is the factory, and who is it for?](01-what-the-factory-is-and-who-its-for.md)). Under which licence, and who holds the copyright?

## Answer

Resolved 2026-11-13 (grilling, in the session written up in [research/fable-opinion.md](../research/fable-opinion.md), section 1).

**AGPL-3.0, for now.**

> "i dont want someone to take this project and sell it as a service to others"
>
> "lets do agpl for now"

- The user was told that AGPL discourages selling SolidTrace as a service but doesn't forbid it: a host must only publish their changes. The Functional Source License (Sentry's) would forbid it, but isn't open source. The user chose AGPL knowing that, so it may be revisited.
- **Ownership:** the user holds the copyright personally. Tagalys is their employer and the first deployment, not the owner.
- **Committed on 2026-11-13:** `LICENSE` (the AGPL-3.0 text from gnu.org), and a "Licence" section at the end of `README.md` with "Copyright © 2025–2026 Shankar Thyagarajan."

**Follow-ups** are in [Which licence follow-ups land, and when?](15-licence-follow-ups.md).
