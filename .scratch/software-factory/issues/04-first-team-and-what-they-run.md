# 04: Who is the first team, and what do they run?

Type: grilling
Status: open
Map: [SolidTrace Software Factory](../map.md)

## Question

Tagalys is the first team to use the factory ([What is the factory, and who is it for?](01-what-the-factory-is-and-who-its-for.md)). What does it look like today, so the first product is built to it?

- How many engineers use coding agents, and which agents: Claude Code, Codex, others? Does the first product support Claude Code only, or Codex too?
- Which forge (GitHub?) and which tracker (GitHub Issues, Linear, other)?
- Do agents run anywhere but laptops yet: CI, cloud VMs, scheduled jobs?
- What would Tagalys' leadership want to see first: sessions, cost, tool use, PR outcomes?
- Can Tagalys' engineers' laptops be pointed at SolidTrace through Claude Code's managed settings, and who would approve that?
- Is a Nomad cluster something Tagalys would run, and on what (GCP, as in `~/Tagalys/infra`)?

Lloyd's talk puts the factory's value at "a team of maybe 10 or more engineers" ([research/fable-opinion.md](../research/fable-opinion.md), section 4).
